# Heloisa Studio

Site e download do **Heloisa Studio**, programa grátis para Windows que corta gameplays
longas em clipes prontos para TikTok, Reels e Shorts.

**Site:** https://brunomariano5.github.io/heloisastudio/

**Baixar:** [HeloisaStudio-Windows.zip](https://github.com/BrunoMariano5/heloisastudio/releases/latest/download/HeloisaStudio-Windows.zip)
(Windows 10 e 11, 64 bits). Extraia, abra `HeloisaStudio.exe`, aceite o termo de uso e
entre com o usuário `admin` e a senha `admin`.
