# CortUp

Site e download do **CortUp**, programa grátis para Windows que corta gameplays longas em
clipes prontos para TikTok, Reels e Shorts.

**Site:** https://brunomariano5.github.io/cortup/

**Baixar:** [CortUp-Windows.zip](https://github.com/BrunoMariano5/cortup/releases/latest/download/CortUp-Windows.zip)
(Windows 10 e 11, 64 bits). Extraia, abra `CortUp.exe`, aceite o termo de uso e entre com o
usuário `admin` e a senha `admin`.
